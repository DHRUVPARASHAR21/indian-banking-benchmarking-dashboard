## Source-handling rules

1. Do not overwrite a source value without recording the new source URL, document date and page.
2. Preserve downloaded filings locally only if redistribution rights permit it.
3. Prefer issuer disclosures over media summaries.
4. Use a consistent basis across banks, and disclose unavoidable differences.
